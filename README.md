# 🇮🇳x🇰🇷 HINKOR-  힌디어 단어장 

힌디어 학습을 위한 개인 프로젝트 기반 단어장 & 퀴즈 서비스입니다.
모바일 사용자 중심 UX와 실제 학습 흐름을 고려해 설계했습니다.

##  프로젝트 소개

힌디어 단어장은 힌디어 단어 위주로 학습하고 싶은 사용자를 위한 웹 서비스입니다.

- 단어를 **보고 · 듣고 · 퀴즈로 복습**하는 흐름에 집중

- **모바일 사용자**를 고려한 UI/UX

- 학습 서비스에서 자주 발생하는 불필요한 인터랙션 제거

*본 프로젝트는 개인 학습 + 포트폴리오 + 기술 기록 목적의 프로젝트입니다.*

## 주요 기능
**✔️단어 학습**

- 힌디어 단어 + 의미 제공

- 단어 발음 음성 재생


**✔️퀴즈 기능**

- 학습한 단어 기반 퀴즈

- 진행 상황을 확인할 수 있는 Progress UI

- 퀴즈 재시작 시 상태 초기화

**✔️다크 모드**

- prefers-color-scheme 기반 자동 다크 모드

- 별도의 토글 없이 사용자 디바이스 설정을 따름

**✔️다국어 지원 (i18n)**

- 한국어 / 영어 UI 지원

- 사용자가 선택한 언어에 따라 UI 언어만 변경

### 기술 스택
Frontend : `Next.js (App Router)`, `TypeScript`, `Tailwind CSS`

State / Data: `@tanstack/react-query`

Backend: `Supabase`
